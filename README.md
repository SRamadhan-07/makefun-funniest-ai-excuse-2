A Python program — standard library only, no network — that writes one line to /output/entry.txt: an AI excuse claiming the task was technically completed, in the timeline where the instructions were written clearly. The line is 96 characters, inside the competition's gate of 1 to 200 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
